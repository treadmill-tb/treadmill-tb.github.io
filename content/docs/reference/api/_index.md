The switchboard serves its API under `/api/v1` on the switchboard origin. The `tml` CLI and the web console are both clients of this API. The machine-readable spec is [`openapi.yaml`](https://github.com/treadmill-tb/treadmill/blob/main/switchboard/api-spec/openapi.yaml) in the repository.
